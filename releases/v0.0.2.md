# v0.0.2

Ubuntu 22.04 images for the Luckfox Lyra family.

## Changes

### Added

- Added CH341 and CH343 USB-to-serial driver support.
- Added support for USB storage, USB HID devices, USB audio devices, and UVC cameras.
- Added RNDIS and QMI WWAN support for USB networking and cellular modems, together with expanded PPP support.
- Added support for Goodix, GSLX680, GT1X, and EDT FT5x06 touch controllers, the ES8311 audio codec, SHTC1 sensors, Bluetooth HCI UART, and RPMsg TTY.
- Expanded networking support with IPv6 routing, MPTCP, WireGuard, virtual Ethernet, traffic control, Netfilter, nftables, iptables, and IP sets.
- Added Rockchip mailbox, RPMsg, AMP, I/O domain, power domain, and hardware crypto support.
- Added commonly used packages to improve out-of-box system functionality.
- Added raw GPT SD card images that can be flashed with balenaEtcher.

### Improved

- Updated and improved the `luckfox-config` configuration utility.
- Improved the first-boot root partition expansion mechanism and storage-space handling.
- Streamlined Ubuntu image generation and packaging.

### Fixed

- Fixed duplicate Wi-Fi initialization on affected Lyra boards, improving wireless stability during startup.

## Quick Start

### Default Login

| Username | Password |
| --- | --- |
| `lyra` | `luckfox` |

> [!IMPORTANT]
> Change the default password after the first login.

### Connect to Wi-Fi

```bash
wifi-connect.sh "<ssid>" "<password>"
```

Replace `<ssid>` and `<password>` with the Wi-Fi network name and password.

## Downloads

Download the image for your exact board model and target storage medium from the Release assets. Each `.img.xz` image must be downloaded together with its matching `.img.xz.sha256` file.

| Board | Available image type |
| --- | --- |
| Lyra | MicroSD |
| Lyra Plus | MicroSD |
| Lyra Pi | MicroSD / eMMC |
| Lyra Pi W | MicroSD / eMMC |
| Lyra Ultra | eMMC |
| Lyra Ultra W | eMMC |
| Lyra Zero W | MicroSD |

Verify the checksum before extracting or flashing an image. See the [README](https://github.com/onepiecettt/luckfox-ubuntu-images#verify-sha-256) for verification and extraction instructions.

## Flashing

Download the official Rockchip flashing tools from [LuckfoxTECH/Luckfox-Lyra-docs](https://github.com/LuckfoxTECH/Luckfox-Lyra-docs/tree/main/Tools).

| Host system | Target storage | Flashing tool | Status |
| --- | --- | --- | --- |
| Windows | MicroSD / TF card | balenaEtcher | Supported |
| Linux (x86_64) | MicroSD / TF card | balenaEtcher | Supported |
| macOS | MicroSD / TF card | balenaEtcher | Supported |
| Windows | SPI Flash, eMMC | RKDevTool | Supported |
| Linux (x86_64) | SPI Flash, eMMC | Upgrade_Tool | Supported |
| macOS | SPI Flash, eMMC | upgrade_tool | Supported |

> [!CAUTION]
> Select an image that exactly matches the board model and target storage medium. Use balenaEtcher only with the SD card images provided by this Release. SPI Flash and eMMC images must be flashed with the corresponding Rockchip tool.
