# Luckfox Ubuntu 镜像 202609

Luckfox Lyra 系列 Ubuntu 镜像首次发布，覆盖 Lyra、Lyra Plus、Lyra Pi、Lyra Ultra 和 Lyra Zero W。

## 支持型号

| 产品系列 | 开发板型号 |
| --- | --- |
| Luckfox Lyra | Lyra |
| Luckfox Lyra | Lyra Plus |
| Luckfox Lyra | Lyra Pi |
| Luckfox Lyra | Lyra Ultra |
| Luckfox Lyra | Lyra Zero W |

## 下载附件

请根据开发板完整型号和目标介质，在本 Release 的 Assets 中选择对应的 `.img.xz` 镜像和同名 `.img.xz.sha256` 文件。

例如：

```text
Ubuntu_Luckfox_Lyra_Pi_A_eMMC_202609.img.xz
Ubuntu_Luckfox_Lyra_Pi_A_eMMC_202609.img.xz.sha256
```

请同时下载镜像和 SHA256 文件，并在解压前完成完整性校验。Linux、macOS 和 Windows 的校验命令请查看仓库首页。

## 烧录说明

本 Release 中的 Lyra 系列镜像必须使用 Rockchip 官方工具烧录：

| 主机系统 | 目标介质 | 烧录工具 | 支持状态 |
| --- | --- | --- | --- |
| Windows | SPI Flash、eMMC | RKDevTool | 支持 |
| Windows | TF 卡 | SDDiskTool | 支持 |
| Linux（x86_64） | SPI Flash、eMMC | Upgrade_Tool | 支持 |
| Linux（x86_64） | TF 卡 | 暂无 | 不支持 |
| macOS | SPI Flash、eMMC | `upgrade_tool` | 支持 |
| macOS | TF 卡 | 暂无 | 不支持 |

> [!CAUTION]
> Lyra 系列镜像不支持 balenaEtcher 或 `dd`。校验通过并解压后，请按照实际开发板型号和目标介质的官方烧录步骤操作。
