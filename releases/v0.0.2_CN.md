# v0.0.2

适用于 Luckfox Lyra 系列的 Ubuntu 22.04 镜像。

## 更新内容

### 新增功能

- 新增 CH341、CH343 USB 转串口芯片驱动支持。
- 新增 USB 存储、USB HID 设备、USB 音频设备和 UVC 摄像头支持。
- 新增虚拟网络、蜂窝通信及网络过滤等相关驱动和功能支持。
- 完善常用外设及 Rockchip 平台相关驱动支持。
- 新增常用软件包，完善系统开箱即用功能。
- 新增原始 GPT SD 卡镜像，支持使用 balenaEtcher 写入。

### 功能优化

- 更新并优化 `luckfox-config` 配置工具。
- 优化首次启动时的根分区扩容机制和存储空间管理。
- 简化 Ubuntu 镜像生成和打包流程。

### 问题修复

- 修复部分 Lyra 开发板 Wi-Fi 重复初始化的问题，提升无线网络启动稳定性。

## 快速开始

### 默认登录信息

| 用户名 | 密码 |
| --- | --- |
| `lyra` | `luckfox` |

> [!IMPORTANT]
> 首次登录后请及时修改默认密码。

### 连接 Wi-Fi

```bash
wifi-connect.sh "<ssid>" "<password>"
```

请将 `<ssid>` 和 `<password>` 替换为实际的 Wi-Fi 名称和密码。

## 镜像下载

请根据开发板完整型号和目标存储介质，从本 Release 的 Assets 中选择对应镜像。每个 `.img.xz` 镜像都必须同时下载同名的 `.img.xz.sha256` 校验文件。

| 开发板 | 可用镜像类型 |
| --- | --- |
| Lyra | MicroSD |
| Lyra Plus | MicroSD |
| Lyra Pi | MicroSD / eMMC |
| Lyra Pi W | MicroSD / eMMC |
| Lyra Ultra | eMMC |
| Lyra Ultra W | eMMC |
| Lyra Zero W | MicroSD |

解压、烧录前请先完成 SHA256 完整性校验。校验和解压方法请查看[中文 README](https://github.com/onepiecettt/luckfox-ubuntu-images/blob/main/README_CN.md#校验-sha256)。

## 烧录说明

Rockchip 官方烧录工具可从[幸狐科技（Luckfox）官方工具目录](https://github.com/LuckfoxTECH/Luckfox-Lyra-docs/tree/main/Tools)下载。

| 主机系统 | 目标介质 | 烧录工具 | 支持状态 |
| --- | --- | --- | --- |
| Windows | MicroSD / TF 卡 | balenaEtcher | 支持 |
| Linux（x86_64） | MicroSD / TF 卡 | balenaEtcher | 支持 |
| macOS | MicroSD / TF 卡 | balenaEtcher | 支持 |
| Windows | SPI Flash、eMMC | RKDevTool | 支持 |
| Linux（x86_64） | SPI Flash、eMMC | Upgrade_Tool | 支持 |
| macOS | SPI Flash、eMMC | upgrade_tool | 支持 |

> [!CAUTION]
> 请确认镜像与开发板完整型号及目标存储介质一致。balenaEtcher 仅用于本 Release 提供的 SD 卡镜像；SPI Flash 和 eMMC 镜像必须使用对应的 Rockchip 官方工具烧录。
